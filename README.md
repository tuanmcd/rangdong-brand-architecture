# Kiến trúc thương hiệu Rạng Đông

Sơ đồ tương tác 4 tầng: thương hiệu mẹ → 6 lĩnh vực (tiêu dùng / dự án) → Hero Product dự kiến → nền tảng RaIO & RalliSmart.

- Xem trực tuyến: mở `index.html` qua GitHub Pages.
- Nguồn sơ đồ: `rangdong-brand.architecture.json` (render bằng Archify).

> Hero Product là đề xuất dự kiến, cần xác nhận với từng khối kinh doanh trước khi đưa vào truyền thông.
